# RUACH Trader Journal - Full Bundle

This bundle includes:
- `services/api/` - Express + TypeScript backend (Prisma) with billing verify, CSV import, TradingView webhook, PDF report generation, S3 upload.
- `apps/mobile/` - Flutter app scaffold with login, trade journal, paywall UI (custom), Play Billing integration hooks.
- `docker-compose.yml` - Postgres + Redis + LocalStack for local dev.
- `.env.example` - environment variables.

See `docs/DEVELOPER_GUIDE.md` for detailed run, test, and deploy steps.
